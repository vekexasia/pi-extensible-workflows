Use a feature document to track a multi-step unit.

Give each task its own line, with an id and the spec requirement it serves.
Update the document after every task transition, including blocked, in progress, and done.
Never mark a task done while its check fails.

This tracking is the convention of this starter; the harness does not enforce it.
